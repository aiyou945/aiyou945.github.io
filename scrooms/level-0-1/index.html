Level 0.1 - "小卖部"

描述：

Level 0.1 绝对是你在学校中见过最棒的地方。

Level 0.1 是一座开在学校门口的小卖部，其整个层级坐落在 Level 0 的街道旁，流浪者可以很轻松地在两个层级之间活动。

与其父层级对比，Level 0.1 的空间更加狭小，店铺外挂着一块塑料牌，上面用红色染料写着“小卖部”三个大字。店铺内部的陈设很简单，只有一排整齐的货架和一个收银台，货架上放满了各种商品，包括但不限于：学生常用文具（如铅笔，橡皮，尺子等），各种各样的小零食（如薯片，辣条，饼干），各科的练习册，饮料（如矿泉水，冰红茶，可乐，雪碧，芬达）。经检测，这些物品均可以正常使用（食物也可以放心食用）。并且，此层级货架上的商品会随流浪者取用自动补充，这代表流浪者可以将此层级作为一个临时的资源补充点，获得源源不断的资源。

同时，由于特殊原因，虽然店内没有安装空调，但流浪者在夏季走入 Level 0.1 会感到十分凉爽，在冬季走入又会觉得特别温暖。S.M.E.G 成员曾经对此层级进行了探查，却都没有发现原因，而此层级唯一的实体“收银台管理员”也不愿意透露。

实体：

此层级没有任何的原生实体，仅存在一名“收银台管理员”（疑似普通人类），性格温和，不主动攻击流浪者，仅在流浪者拿取商品后要求支付少量“层级代币”（可通过自己的普通物品兑换）。在一些情况下，该实体还会免费赠送给流浪者一些辣条。

需要注意的是，实体“老师”也会偶尔徘徊在 Level 0.1 的出口附近，不建议流浪者在此层级内停留太久。因此，此层级并不是一个理想的适合长期居住的层级。

基地、前哨和社区：

S.M.E.G——放学购物党：由人类同学组成的小型组织，在“放学时间”会集体来到 Level 0.1 进行抢购，他们对于实体“老师”的偷袭已经有了应对的方法与充足的经验，他们欢迎新的流浪者加入。

R.S.S——课间补给社：由常驻 Level 0.1 的学生流浪者组成，他们熟悉小卖部的补货规律，会帮其他流浪者 “代购” 限量零食和绝版练习册，偶尔还会组织 “课间摸鱼” 活动，在收银台旁的角落分享八卦。

入口和出口：

入口：在 Level 0 走向街道旁的小卖部即可进入 Level 0.1；你也可以通过在 Level 1 走入一条隐蔽的小路来进入 Level 0.1，且可原路返回。但是，这条小路一般非常隐蔽，让人难以发现，所以不建议流浪者用这种方法进入 Level 0.1。

出口：走出小卖部的大门可以回到 Level 0。
