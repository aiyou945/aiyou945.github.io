Object 1 - "作业"

等级：安全？ 常见指数：极其常见 评价：对生存有极大帮助
含有一定危险性及精神伤害

流浪者 dtjg123 上传的作业本示例图片，可能与真实情况有所差异。

Object 1 是 The School Rooms 中的一种常见物品，它具有多种不同的外观，但其本质都大致相同。

Object 1 的外观有很多，但大多都呈现为由硬纸壳、塑料、牛皮纸等材料包起来的本子，与 Object 6 的外观极其相似，但流浪者依旧可以通过以下方法很轻松地分辨它们：Object 1 中记录的大多是练习题，其内容大致包括：选择题，填空题，解答题，主观题，阅读题，翻译题，资料分析题，作文题等；而 Object 6 中记录的则大多是课文、新例题等（也包含一些练习）。

作用

Object 1 最主要的作用除了帮助流浪者巩固知识以外，还可以帮助流浪者化解“老师”的攻击：在每天早上来到学校后，流浪者会被要求上交 Object 1 给“老师”，并由流浪者中被“老师”给予称号“组长”或“课代表”的成员将 Object 1 送至 Level 4 接受批改、检查。若完成 Object 1 的质量不过关或流浪者没有及时上交 Object 1，流浪者将会遭到“老师”的训斥，严重者可能会被给予更加严重的惩罚或者叫“家长”。

如何完成 Object 1？

完成作业（下文指代 Object 1）是所有流浪者每天被安排的任务，而需要完成作业的多少大多由“老师”决定，流浪者在学习的时候需要记清楚作业是什么，需要怎么完成，有没有什么特殊要求等，回到“家”后使用 Object 2 完成它们，并使用 Object 3 将它们重新带到学校。

注意：务必要认真完成作业，不要抄袭，否则更可能收到“老师”的惩罚！

常见问题解答

Q：我忘记带作业来学校了，怎么办？
A：保持冷静，你可以前往 Level 0.9 打电话请“家长”送来，切记，要在“老师”发现之前！

Q：今天的作业实在太多了，我可以不写吗？
A：请记住一点：无论作业有多少，只要“老师”声明必须在第二日上交作业，无论以任何方式（除了抄作业），都必须写完！如果你实在感到力不从心，可以选择先去休息，第二天早上早起完成剩余的作业。

Q：周末作业一定要在周五写完吗？
A：不一定。如果周末作业很多的话，可以合理分配到周六或周日完成；但如果被“家长”强制要求，还是建议在周五认真完成，这样分配可以增加周末空闲的时间，方便流浪者恢复理智。……

Q：有一道题我一直不会做，已经卡了 1 小时 18 分钟了，我应该继续琢磨吗？
A：建议先做后面的题，过度琢磨一道题可能会浪费你的时间，如果你看了一道题很久都做不出来，建议先放一放，这样可以节省你的精力、时间和理智值。在 The School Rooms 中，理智是非常重要的。

如何获得 Object 1？

在一般情况下，流浪者会在开学第一天领到作业，你也可能被“家长”强制布置作业。

再次强调：过度使用 Object 1 可能会导致流浪者的理智下降，而导致精神疲劳，甚至做出一些奇怪的举动。在感到疲劳的时候，尽量休息（除非迫不得已）！

行为准则

应当：

  • 按时认真完成布置的 Object 1。

不应：

  • 抄答案或胡乱做题
  • 故意不做作业
